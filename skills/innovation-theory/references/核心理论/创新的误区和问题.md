# 创新之路 / 创新理念 / 创新的误区和问题

**[00:00]** 其实我们已经说了不少创新和创造的区别，那么我们再说一下创新的误区和创新的一些问题。我们在社会上现在很多情况下确实是普遍的存在，给我们带来了很多的困扰。我作为一个学术研究、理论研究的人，也是想把这些给大家多说一说，希望有更多的朋友能认识到这个问题，咱们能共同的来避免我们在创新过程中间的一些问题。首先创新创造不分，就造成什么？盲目的技术崇拜，以为高技术就是好的。我们现在社会总是崇拜高技术，总是崇拜TMT，这是不对的。真正的仔细想一下，你在你的生活中间有多少是高技术？高技术离你很好，但是离你其实很遥远。当然对于一个文科生，也许觉得理科生的每个东西都很高大上，但是对于一个技术体系的专业人士而言的话，那么才谈得到他高还是不高。所以不要盲目崇拜技术。你比方说对于管理专家来说，某些管理手段就不是一个很难的事情；但是对于技术专家来讲，可能某些技术对他来讲已经是很成熟的东西了，虽然他用的是很成熟的，但是在外人面前可能看上去是高大上。所以我们在这个技术不要盲目的崇拜技术。现在盲目的都是高大上，都是——我们把它叫——一听是AI，一听是VR，一听是人工智能，一听是机器人，好像就高大上。我们全社会都在追求这些虚无的或者说高精尖的东西。大家要知道，一项技术不在合适的时间、合适的地点，它是一文不值。你拿石墨烯技术去解决一个我们假设是一个农作物的生长的问题，它就干脆就很难用得上。

不要再逼企业搞创造性研究，这一定要把创新和创造要搞清楚，不要去盲目崇拜高科技。就要让企业要去做的话，就结合它的实际的需求。就像我们不能因为我有了个锄头就一定要去种地，也不能说是我现在要是种不同的地，我们要根据不同的地、不同的时期，看是要用铁锨呢，还是用镐头呢，还是用锄头。所以我们不能是因为我们有了锄头就一定要找地去除，而是因为我们要种这个地，在不同的时间我们才需要不同的技术，这是一个本质的差异。所以我们把创新和创造确实要分清楚：企业只能搞创新，企业绝不能搞创造；科研单位、大专院校它最适合搞创造，它没有办法，让它去搞创新它就心不在焉，它也没有那个强，它也没有那个动力。

第二呢，我在创新的这个误区里头，还有个衡量标准的一个错误。就是创新水平高不高，大家看看你是团队高不高、学历，团队水平高不高、学历，水平高不高，技术是不是新奇特——这就是一个衡量标准的错误。我们现在在申报一个项目的时候，你可以说一张表，对于创新专家来讲没法谈，要是我去填的话，我为什么享受不上国家的这些资助呢？他们在衡量一个你是不是创新的技术的时候，他就衡量你是来源于什么，你是跟大专院校合作没有，你有几个专家，你有几个学者，你有几个团队。所以我们要是这样的一个衡量的标准错了之后，会严重的限制一些社会的创新成果的出现，和创新人才的一个奖励或者说是吸引。

还有就是创新的这个过程中间实施主体的错误，总是认为创新的主体、主力军是科研单位、大专院校、科研院所，其实这是错误的。我们前面已经说过，这个创新是一个经济领域的一个词汇，创新的更多的主体主要是来源于市场需求，来源于生产一线。而科研单位、大专院校，他们研究的是创造性的劳动，他们以研究未知的东西，设法把未知的变成已知，人不了解的变成了解，它不是基于市场的，它是基于科技进步和人类的好奇心的。因此他们所做的事情和创新实际上是完全是不同的。因此我们要让一个企业一定要去跟大专院校合作，这个某种意义上的确实能带给他们一些需求，但最大的问题是企业创新需要成熟技术，大专院校、科研单位带给他们的都是不成熟的前沿的东西，所以他们两个实在是找不到交集，不应该再拉郎配，该干什么的就去干什么。那这样就导致了什么？实施方法的错误，就是总是拉郎配，在搞产学研合作、校企合作，这是要不得的，就不应该让他们有这样的情况。而且应该是什么？就是我们对企业的奖励和鼓励，就应该企业干得好我们就给他。他的企业创新好，我们给他奖励，鼓励企业做创新性的应用研究，而不能鼓励做创造性的这种劳动。一个企业只有百分之几的正常，只有百分之几的这个利润，你拿出百分之几的利润去搞科研，那你可能如果搞那未知的前沿的科研，那根本连个响都听不见。所以我们要对创新产生的这个创新的误区和问题要清醒的认识，不能是创新创造不分、衡量标准不正确。我们把实施的主体要搞准，把实施的创新实施的方法要找正确，不能走错了。
