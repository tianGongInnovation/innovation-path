# 创新之路 / 创新理念 / 创新的具体方法

**[00:00]** 我们再说一说创新的一些具体方法。创新其实它的方法很多，我们有很多这样的一些成语。比如说洋为中用、古为今用，这是什么呢？这就是抄袭，这也是学习。把洋人的东西我们拿来作为中国人来用，古代的东西拿到现代来用，那么也实际上就是把别人的东西拿来给自己用。抄袭、学习，这是人类这么多年或者人类的历史上的最主要的一种知识传播和知识使用的方法。你得学习知识，不光是我们学习别人的基本原理，我们学习别人的应用模式，包括师父传授徒弟，那不是让徒弟学会师父怎么做、师父做的东西吗？所以创新的具体方法非常多。

还有他山之石可以攻玉，这个说的简单的一点就是两个字：跨界。也就是说我们用别的领域里头的一些工作的工程的方法，来解决我们现有的问题。还有继承和发扬，不断的进步，扬弃，或者叫与时俱进。第四呢偷工减料、降本增效。我们光说偷工减料，那如果偷工减料达到了好的效果，那当然是正面的了。我们能把工省下来，能把料省下来，如果能达到同样的效果，当然是值得表扬的。但是如果你偷了工减了料，你成了一个伪劣产品，那当然是要批评的了。所以我们偷工减料是方法，看你用在什么目的和产生了什么样的效果。我们的目的本来应该是降本增效，降人工、降材料，增加它的能效，至少要达到同样的能效。这个当然也是一个技术，你必须要有技术，你才能偷得下来工，才能减得下来料。就像我们改革开放之初的时候，说我们偷工减料，是我们不得不偷，我们设备没有人家的好，我们的材料没有人家的强度高，没有人家的硬度好等等，我们什么都比人家的差，我们还想做出来，还不能等死，那么还得做出来一个和别人相近的、或者几乎能达到它的同样功能的东西，那怎么办？你只能用现有的工、现有的料、现有的设备、现有的能力，还得做。我们当年的这些义乌，我们当年的慈禧，那就是我亲身经历，他们利用他们现有的设备、现有的材料、现有的工艺，制作出来几乎都不能使用的东西，但是他们很有耐心，他们到处去推销这个几乎不能用的东西。而我们作为一个科技工作者，被他们的这种认真和努力所感动，我们也尽可能地用它的插线板，用它的接插件，确实很难用，确实效果很差，但是他们也不厌其烦地不断地改进，我们也提意见。最后慢慢慢慢经过这么多年的发展，现在我们的公牛的插板完全不次于国外的东西。得给它机会，如果不给它机会，那么它永远没有机会，我们国家的芯片也是这个道理。

还有我们叫回到初心。就是我们现在很多比比皆是，你比方说咱们灭火，古人灭火用水，今天灭火还是用水，这是不是有点问题？古时候除了水还有什么能用吗？没有东西可用。今天我们有能更好的实现灭火的隔绝空气、降低温度的东西，比方说液态的二氧化碳、干冰、液氮等等，这些东西就不能再用几千年前使用的水、一两百年前使用的干粉、几十年前舍不得用的二氧化碳灭火器。现在完全不同了，现在的二氧化碳一吨才一百多块钱，又环保又高效，为什么我们所有的消防队还只配水呢？大胆的突破一下。我们要打破历史局限性，回归到我们本源，我们再考虑一下，我们灭火靠的是什么？降低温度，什么能降低温度？隔绝空气，什么能隔绝空气？我们以前做不到，我们现在用一个巨大无比的降落伞，把一幢楼一旦燃烧了之后，我们把它罩起来，能不能做到呢？以前不敢想，现在完全可以想了。所以我们应该回到初心，打破自己的条条框框。第六呢要与时俱进、大胆的发展，和回到初心类似。我们很多的应用理论呢习惯了，习惯了之后呢觉得可能不行，觉得应该是这样，觉得我们前人都已经看得挺好了，但是前人的机械加工能力、材料的工艺、控制的工艺都不行，为什么前人做了我们就必须要照做呢？应该结合我们现在的材料、现在的控制、现在的加工工艺等等等等。以前的压力上不去，现在上去了。就像我们的无人机，有什么理论的进步吗？没有太大的理论进步，电动机带个叶片，我在小的时候就有，飞不起来，为什么飞不起来？因为电动机不行。现在就因为电动机突飞猛进的发展了，所以同样的一个原理，几十年不行的现在能做到了，这当然要与时俱进了。

还有要实事求是、别怕专家。很多的专家——我们这样说，见的太多了——很多的专家是时间熬出来的，是有那个知识，他没那个能力。很多的专家是靠考学考出来的，靠时间熬出来的，是靠别人推举上去的，甚至靠自己争取过来的，不见得是真正的专家。我们很多的专家天天评审，飞来飞去讲课，已经很少亲自做实验，很少去学新的东西了。我跟有的专家交流一些现代的新的东西，他连听都没听过，那他怎么能用呢？还有呢，接着这样说的话，就是要见多而识广。很多人创新，我们创新来自于什么？不是天马行空，不是胡思乱想，是因为你见多识广。有了很多更多、数不清的直接经验、间接经验之后，你才能有一个什么洋为中用、古为今用、他山之石，你才知道哪有这个石，你才知道继承什么，你才知道偷这个功用什么、捡这个料用什么等等等等。所以见多识广这才是创新的基础，而绝对不是天马行空、胡思乱想、信马由缰。
