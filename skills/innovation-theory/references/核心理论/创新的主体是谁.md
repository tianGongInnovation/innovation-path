# 创新之路 / 创新理念 / 创新的主体是谁

**[00:01]** 创新者是谁呢？是谁来创新的呢？这是一个很重要的问题。创新者就是指推动创新过程的人。有专家说呢，创新者就是企业家的代名词，这个我觉得不完全正确。这个创新我们前面有个定义，创新是什么？如果是技术创新，它是指成熟技术结合市场需求的具体应用。那么在这个概念上，我们创新的不仅仅是企业家，它是在整个生产生活、社会中间打拼的每一个人。企业战略创新是企业家的事情，产品创新是工程师的事情，销售方法模式创新是销售经理的事情，工作方法创新是文员的事情。不管怎么说，不管是哪一个活动、哪一项行为，实际上它都需要执行者不断地去创新。它不光是科学家、政治家、领导和企业家的事情，它主要是一线的。不管你是战场、商场、生产、农场、管理者，应该说还有一个特点：什么是创新呢？就是一线的劳动过程中间往往是需要产生创新，不是一线它就不是创新。

那么我们再举几个例子，就是因为创新是成熟的技术结合需求的具体应用。我们在战场上以前就有过很成功的一个创新的例子：战士发现子弹，就想挡住子弹，那怎么办呢？靠血肉之躯是没办法，要冲锋怎么办？战士们发现这个被子湿了水，它就很韧、很有韧性，子弹打上不容易打透。那么战士想要冲锋的时候，在以前解放战争中间，他没有什么凯弗龙的防弹盔甲、防弹衣，那怎么办？用门板顶上被子，被子上面浇上水，然后顶着门板向前冲，最后子弹打过来，然后打在门板上、打在被子上，最后挡住了。那么战士冲上去以后呢，就冲到敌人面前的时候再进行肉搏战，然后再近距离的格斗。如果没有这样的湿被子的话，那么可能它还没冲几步就被榴弹、就被子弹就打倒了。所以这样一以来呢，就是产生了简单的一个防弹的一个装置。还有我们炸药包要靠人扔上去，那一个人的扔呢最多也就扔个十几米，几公斤的炸药包扔不远。但是有的时候如果我们想要抛到一百米、几十米之外，那我们又没有排气炮，有炸药包，那怎么办？有人发明了什么呢？是在一个桶里扔点火药，然后把炸药包放在上面，最后把点着一段导火索，然后扔到桶里面去，之后这个桶里面的炸药猛的一炸，就把这个炸药包给抛射出去了。这些是典型的在具体实战过程中间实在没办法了，我们想出来的奇招。被子是现成的，门板是现成的，水泼在被子上是一个现成的东西，子弹是打过来的，那怎么办？就用这些全是成熟的现成的东西，我们竟然产生了防弹的这样一个特殊的效果。我们炸药包是现成的，桶是现成的，火要燃烧会猛然的产生冲力，这个是现成的，结果就这样的巧妙的一个组合，就竟然能把炸药包产生这种土大炮的一个作用。一个炸药包抛到了一百多米远，要是爆炸以后可以抛在对方的战壕里，抛在对方的城墙里面去，那这种结果可能起到了榴弹炮的作用。这就是典型的创新，是谁干的？这不会是毛主席干的，这也不会是朱总司令干的，这就是一线的战士们突发奇想，也是不得已，为了解决敌人、为了消灭敌人想出来这些特殊的一些方法。所以他更多的是一线的。

那么销售员想出来一些新的销售方法，那不一定非得每个点子都得是销售总管去考虑吧。所以更多的，特别是很多人呢，假设是领导，他不知道一线的事情，他怎么能想出这个水桶、铁桶加上火药加上炸药包呢？所以有些时候如果是闭门造车，是在后面、在后方的话，不接近于市场一线，它不可能是创新者。它也可能是个创造者，但它不会是创新者。
