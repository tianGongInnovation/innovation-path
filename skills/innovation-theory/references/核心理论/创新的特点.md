# 项目投资价值评估 / 相关投资理念 / 拼创业创新大赛项目甄别原则

**[00:01]** 关于我们拼创业创新大赛项目甄别的一个原则，我们也非常明确：我们是一个创新大赛，为了创业的创新大赛。我们第一条，非创新项目不投，或者说不支持——我们应该叫不支持，或者说不欢迎。什么是创新项目？我们的定义也非常明确，就是技术理论成熟、市场需求紧迫、短期容易出结果的项目，就是创新项目。

什么是技术理论成熟？技术理论成熟是指就是比方说我们现在人人都在做的、人人都在用的，比方说冰箱技术就很成熟，比方说自动驾驶技术就不成熟。虽然他说我们实际上已经很成熟了，没有大范围的推广使用的技术，那就不是成熟技术。我们只是说人人都在用、用的都已经不值钱的技术，那叫成熟技术。第二呢是市场需求。未来的自动驾驶行业有很大的市场空间，那是未来，我们只是说现在。比方说我们在用饮水机的时候，这个饮水机呢它现在都是高耗能烧热水，那么我们饮水机呢可以改成这个热水、温水、冰水、冻水、冻水冰块同时提供的。当然了这个市场需求不需求呢，那对外行人可能不需求，对有些人呢是有很强的一个需求。像制冰块，那么可能港口，那么渔港，那么他有大量的这个冰块的需求，但是对一般的人他就没有需求。所以我们还是——制冰很成熟了，但是冰块需求量很大，但是对有些人需求量很大，对有些人没有需求。那么对于我们的应用场景，如果是一个对渔港的市场很清楚的一个人，他是认为制冰很成熟，但是制冰的技术有创新，有节能、有改进，对散热进行改进，对制冷进行改进，用成熟的材料、成熟的工艺、成熟的方法去改进，解决大量的冰块的制造的这么一个过程，这就是创新，而且做了马上就有人用，这叫市场的紧迫的需求。短期容易出结果，就是我们改一下马上就能看到，我们改一点能看到一点，改两点能看到两点，很快就能把它改出一个结果的，那就是创新项目。

第二呢，我们项目甄别的时候，我们给出了的一系列的一个不支持项目清单。那么大家在自测的时候，参赛者在自测的时候，在选项目的时候——当然选我们的项目，能进入我们项目库的，我们都是认为符合我们的要求，肯定一般不在，或者说它的条件是不满足这个不支持项目的清单的。在这个不支持项目清单里面，如果一个项目有两条以上情形符合，那就很可能不符合我们参——就是很可能就不符合我们参赛的这么一个标准。也就是说我们这里头有一个不支持项目的清单，但是它不是说一个项目有一项就不符合了，应该有两项以上，那就是很大的概率就不符合我们的参赛标准了，所以大家可以自测，我们也有一个很明确的一个不支持项目清单。

第三呢，我们也特别的指出，就是我们大赛的总工程师，我们大赛的这个项目组呢，有权决定某个项目通过或者不支持的权利。原来有些项目呢，我们觉得可能我们前期订的这个不支持清单是否定的，但是我们也允许，我们说这个项目可能在我们的不支持清单之外，我们还是支持的。虽然说有几项好像是跟我们的不支持清单的里面是符合，但是我们认为也是可行的，所以这个权力在大赛。但是有些项目按照我们现在的不支持清单并没有说它不满足，但是我们最终还是有权利决定这个项目我们不接受，或者说我们不支持、不欢迎。所以这个第三条也是给予我们自己的一个自主权，相当于是解释权在我们了。
