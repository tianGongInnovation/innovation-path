# 创新之路 / 创新理念 / 什么是创新

**[00:01]** 今天我们谈谈什么是创新。创新这个词啊，大家现在是天天都在听见，几乎无时无刻不涉及创新，我们天天在喊创新。但是到底什么是创新，你考虑过没有呢？你真的知道什么是创新吗？如果你要是不花一点时间去弄清楚什么是创新，那你天天喊我们是这个创新那个创新，那你到底做得对不对呢？

关于这个创新有很多种说法，其中有一种说法呢，他是说所谓创新，概括的说，就是所谓既成前人又不因循守旧，借鉴别人又有所独创，努力做到观察形势有视角，推进工作有新思路，解决问题有新方法，使各项工作体现时代性、把握规律性、富于创造性等等。听上去还是挺押韵的。那么我们查一查百度，百度上面的定义是什么？创新是指以现有的思维模式提出有别于常规或常人思路的见解为导向，利用现有的知识和物质，在特定的环境中，本着理想化需要或满足社会需求，而改进创新的事物、方法、元素等等，并获得一定有益效果的行为。我觉得听到这儿你应该挺糊涂了吧。我呢也查过很多，别人也有，大家也有，名家也有，专家写的各种各样的关于创新的东西，基本上来说都在——基本上都是长篇大论。也就是说以把别人说糊涂为目的，以表现的自己比较专业，别人听不懂，都是一些生僻的一些专业词汇，来体现出这个定义的复杂性、定义的水平。我觉得没有可操作性。

我这个人喜欢找规律，喜欢把复杂问题简单化。那么最后我通过寻找他们的共性、他们的合理的地方，对他们进行化解再化解，我最后也做了自己的总结。在这之前，我还得益于听过一个秦俊伦教授的创新经营，其实也是他的这篇这个创新经营这个教程，使得我对创新产生了兴趣，使得我对创新这个词发生了兴趣。所以他呢也带给我的灵感，几乎我做出来的总结也是向秦教授学习得出来的。我的总结，创新非常简单：创新是成熟理论结合具体需求的实践应用，成熟理论结合具体需求的实践应用。用到技术创新，就是成熟技术结合市场需求的具体应用。就这么三个部分，注意，三要素：一个是成熟技术，一个是市场需求，一个是具体应用。这三个要素少一个都不是创新——不是成熟技术，它不是创新；不是市场需求，它不是创新；不去行动，也不可能形成创新。

创新人人离不开，创新每时每刻都需要。秦教授的话说，不创新就死亡。我们后面会在其他的各个部分中间，对我们所提出的这些理论观点做进一步的梳理，希望大家喜欢听。
