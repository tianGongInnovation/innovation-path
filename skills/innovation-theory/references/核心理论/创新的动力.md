# 创新之路 / 创新理念 / 创新的动力

**[00:01]** 创新的动力。其实我们在前面说了，创新是成熟——特别是以技术创新为例，它是成熟技术结合市场需求的具体行动实践。那么这一点上来看，那么需求确实就是创新的动力，一定要抓住需求。这个需求是什么？就是市场需求。如果是创新、笼统的创新的话，那么就是市场需求。当我管理管不好的时候，那就有管理需求；当我发展做不好的话，那就有发展的需求；那么销售做得不好的话，那就有销售的一个需求。那就不断地有的需要：市场创新、管理创新、发展创新、销售创新、制度创新——制度不合适，我们制度创新。这就是它要有根据实际的需求，一定要抓需求。

我们要防止的问题是什么呢？就是它有一些虚假的需求，或者说主观的需求。所谓虚假的需求就是，就像我们前面说我们发明了这个车的新的绿色动力的问题，那么车确实有几亿辆，全球有十亿辆，那我能不能控制得了这个市场？或者我能不能接触到这个市场？我作为一个技术人员，我没有汽车制造厂，我没有汽车这个圈子，我光看见未来有这么大的市场，那你说它是我的需求吗？不是，那么至少它现在还不是。所以这叫做假需求。当我签了一个改造汽车的订单，这才是真需求。另外还有主观需求，比方我们的电动汽车，我们要弯道超车，我们要节能减排，它不是一个基于事实的东西，它不是一个基于规律的东西，它是一个长官意志，它是一个主观愿望的一个东西。它不是需求，它必然不会产生创新的一个成果，它是不会的。所以我们要抓住的是什么呢？要直接需求，不能找这些所谓的间接需求、想象的需求、感觉的需求，或者是主观意志的需求、领导意志的需求，这些都不是需求，它都不可能产生创新的成果。那么最后的结果，如果你不是这些，你发现错误的时候你会得到一些东西。如果你发现自己创新到底是不是创新，创新是不是方向错了，那你就能衡量是什么。首先有些技术转化不了，转化不了是什么？这个技术就不是市场需求来推动的技术进步，那么这个技术它就不能转化。还有有些人做出了一些产品为什么卖不出去呢？就是因为它不是基于市场，或者对市场的了解不够深，它没有抓住市场的真实需求，最后导致你的产品就卖不出去。也许你三门的改成八门冰箱了，那这个事情它是一种成熟技术的创新应用，但它不是市场需求，你怎么把一个八门冰箱卖出去呢？最后就会造成各种的资源的闲置的浪费。

所以我们在确定创新的动力的时候，不能是主观臆断，不能是虚假，不能抓住虚假的，所以我们一定要抓真实的东西。我在做了很多的理论研究之后，有人说你找一个最好的技术，咱们一起把它做起来。我说什么叫最好的？最好的是什么？市场说好的就是好。虽然我的每一个技术、每一个产品，我相信未来是有巨大的应用的，但是如果让我现在就投身到市场上去的时候，我没有销售团队，我没有市场的触角，我没有一些广泛的4S店的，比方说这样销售网点的支持，让我要去做这个东西，那么市场虽然存在，它不是我的。你说金子埋在地下，那是挖金矿的人的，对吧？鱼在海里头，那是渔民们的市场，那不是我，我是在内地的这么一个人。所以社会上的资源那么多，有些人觉得哎呀，有些人这个人干这个挣钱，有人干那个挣钱，是有人干那个挣钱，不能是说大家的钱都是我的，大家的市场都是我的。你能抓得住的市场才是你的，你抓不住的市场那是别人的。所以我们创新的动力来源于市场，来源于需求，但是我们要知道这个需求确实是能抓得住的、能签了约的、你能控制得了的，或者你和你的合作伙伴合作以后能控制的，那才是真的需求，那才是你创新的动力。
