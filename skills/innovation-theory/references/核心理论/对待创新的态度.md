# 创新之路 / 创新理念 / 对待创新的态度

**[00:01]** 对待创新的态度呢，我们再重申一下创新是什么。我也说我做了很多的工作去研究到底什么是创新，最后呢总结出来是什么呢？通过各方面我们化解同类项，然后呢分析、梳理、总结、提炼，最后我们得出：创新是什么？创新是成熟技术结合实际需求的具体应用。三要素：第一是成熟的东西，不论是成熟的理论、成熟的技术；第二是真实的需求，不是虚假的需求，不是主观臆断的需求，不是你猜测的需求；第三是要去行动，不能光说不练。这三要素缺一不可。我们做创新，很多人就觉得创新由于是成熟技术，你这个不是高大上，你这个不是量子，不是纳米，不是FAST，不是小太阳，不是散裂中子源。创新不丢人。我们不同的人干不同的事，科学家干好他的创造，去研究从无到有的过程，去研究高大上的东西。我们作为工程师、工程技术人员，作为企业的产品工程师，作为大楼的建筑师设计师，我们一定要创新，我们不能玩创造，我们必须做好创新。创新虽然技术含量可能是由于它成熟，它当然不高，但是它的风险小，它的成本低，它的见效快，它容易掌握、容易普及。我们做好我们不同领域的事情。我们创新是经济领域的事情，我们有本事我们把钱挣回来；而他们创造是科技领域的事情，他们有本事把论文发表了，咱们拿诺贝尔奖。大家各干各的，没什么高没什么低，我们干好自己的活，好人生就行了。

我们这个创新它不高、不深、不神秘，但是它是人类进步的可以说主要的动力。我们牛顿定律发明，没问题，这是创造；但是牛顿定律的应用，那都是创新。因为它已经是存在了的东西，我们用在这里是创新，用在那个领域是创新，我们把它这样用一下是创新，那样用一下是创新。理论仅仅是个开头，如何能用好理论更重要。所以我们人类实践和前进、人类发展的主要的过程和主要的成果，是创新得来的。当然了创新要基于创造，但是创造只是开了个头，有了这个理论你不去用，什么都没有用，不对也什么得不到。

我们再说，在创新的过程中，知识产权要合理的重视。我个人一直在宣传，我们劳动是等价的，不能因为脑力劳动和体力劳动就厚此而薄彼，既不能特别突出脑力劳动，也不能随便的贬低另外一方，比如贬低体力劳动。大家都是劳动，都是汗水，都是人。我们讲平等，就应该我们农民种地一年下来的辛苦，和我们科技工作者一年的辛苦，领域不同，大家要同等的对待，既不能厚此也不能薄彼。我们实际上一些伟大的科学家们，其实他们做的本来就挺好，他们并没有高高在上，自己认为自己高人一等，这些才是他们的本色，也是他们是伟大的基本的东西。而且我们认为技术有、产品有保质期，技术当然也有保质期。产品消耗掉了需要再生产，技术熟悉熟练了之后我们需要再创造。我们搞技术创新的人就应该不断的创新、创新再创新，就跟农民今天种地明天还要种、明年还要种，只要是生命在我们就要劳动，道理是一样的。所以不要把创新或者创造想的那么神秘，想的那么高人一等。我们做着这种技术的进步或者技术的内容，前面也说过了，工具主要在于用，不用就是废物。我们这么多的学生学了那么多年的微积分理论，不用，连理念都不会用，那你学了不是白学吗？燃烧生命，浪费社会资源，浪费自己的家里头的金钱和自己的时间，有意思吗？所以不管是什么工具，没有用就是废品，占地方。

还有呢，对于创新这个过程，我们建议应该是采用合作共赢。我们说一个技术的创新的一个例子：有一个澳大利亚的野外摄影师，发明了一个有无限焦距的、就等于有无限景深的一个镜头，就是突破了传统的思维。什么意思呢？就是近处的物体和远处的物体都能在一个平面形成清晰的像。这个东西呢，就是它的这个镜头呢，现在斯皮尔伯格早就开始在用了。这样的话他就把拍前景和拍背景的两次拍摄变成一次直接拍摄。他当时就把权力授权给一个镜头生产商，结果其他的镜头生产商联合起来，以他欺诈等其他的法律的一些手段告他，最后因为以欺诈的名义把他所有的专利全部都否决了，这样他就破产了。这是在美国的案例。也就是说技术如果你要去形成垄断，这是不得人心的，是没有出路的。即便在美国那么号称重视知识产权的，他嘴上号称重视知识产权，但是他资本还是第一位，大家合起来通过歪门邪道，照样的把你整下去。所以我们还是要少树敌、多合作，垄断没有出路。国外为什么讲究知识产权呢？他是要靠垄断，靠他的前面获取的这些技术来剥削别人。咱们这样想一下，如果我写了一本书，最后我这一辈子就靠这本书吃饭，这本书确实有用，但是这本书我就要垄断了，以后这本书一辈子、几十年、几百年都要靠这本书收版权费。那么我觉得我的劳动写这本书很辛苦，确实用了我毕生的精力，我的毕生跟别人的毕生，跟几百人、几千人、几万人的毕生，难道我就高那么多吗？我觉得我没那么高，我觉得这种方式这种劳动是不等价的，不是这种劳动呢不能这样去衡量。所以国外呢他们当然希望了，我用知识产权来让你们的劳动变成低成本的劳动，我的劳动变成高成本的劳动，这是他们的愿望。但是我们觉得呢，形成垄断没有出路，至少我们将来不能像他们这样做，他们有些做的事情我们做不到或者不应该去做。

我个人呢，反正我是身体力行。我申报专利我是一种宣誓：当然我不希望我在使用一项技术的时候，那么别人来告我侵权，因此我先要申报，我这宣誓我先发现的。第二呢，在申报专利的时候实际上就公开了，公开我不丢人呢，而且我的专利说得清清楚，说得越清楚其实保护得越到位。还有呢，专利本来就是有时效的，我也是接受，十年二十年，特别是当过期之后，时效过了以后它是大家共享的，没问题。还有专利应用我是讲究合作，我就说大家能合作最好，你别担心，我不会是大开口。但是如果你要是自己去做的话，可能没有专利的最早申报人了解的那么清楚；如果你比我还懂得多，那么你去用，没关系。还有专利是有权利的，如果你用了我的技术挣了很多的钱的话，我觉得合情合理你应该给我一些；如果你没用，那你的利益是你的。所以在这方面我个人是努力的去做的。特别是假如说有的人说，那有人要是拿了你的专利也做了一些挣了一些钱，我说挣的不多、挣的小钱无所谓。这个就包括有的专利人家引用一下，有的专利人家自己做个实验，有的专利改了几辆车，挣点小钱无所谓。这就是我们对创新成果的态度，我希望大家都能理解，大家都这样去做。
