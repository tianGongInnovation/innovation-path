# 创新之路 / 创新理念 / 试论创新思路说明

**[00:00]** 这个录音是关于我们对创新的一些思考和探索。我想花点时间和精力，这些年也是我在创新这个词上所花的精力居多。我在平时的时候和朋友们交流的时候提出我的理念，也是在饭桌上也给大家带来一些谈资，大家还是议论的非常的热烈。那么这里头牵扯的一些内容，就是写起来还是有一定难度，考虑了很久，收集了一些素材，也进行了几年的深度的思考，我认为是成熟了，但是现在要把它整理起来是要花时间的。这里面基本上它牵扯的主要的内容，或者题目上，我现在初步的想是创新与创造。但这个题目不好的地方呢，它是研究创造，我呢实实在在的说，我对创造的兴趣不是很大，我对创造的这个词的研究呢也不是很多，所以你让我把创新和创造同时来进行论述的话，我第一没有太多的兴趣，第二我也没有太多的深度和感受，所以我觉得这个题目也不是太好。试论创新呢，这个题目呢是可以，也比较含蓄，但是这个呢也有它的问题，就是这个创新呢以这样的形式去说的时候，可能很多人觉得它还是高大上，还是高高在上，可能我跟别人一样也是说了一大堆没什么可以操作的东西。

那么我还是想试试看，像白话创新或者白话技术创新。这个首先解释呢，白话有在百度啊，或者百度和辞海上呢，它有两个解释：第一个白话呢是指粤语、广东话；第二个白话呢就是用俗话和通俗的方式来描述。我们这个当然是指用通俗的方式来解释创新。在创新这个词呢这展开的时候，其实啊我们是白话创新。在我们要是写这篇文章的时候，我们更多的要探讨的是技术创新。我是一个自然科学工作者，当然我也研究一些社会科学的东西。所以创新这个呢，它是一个理念，但是说是用成熟的理论，根据具体的需求来进行产生新的一些解决方案，最后得到应用。也就是说，是成熟技术结合需求的具体应用，成熟理论结合需求的具体应用，这是我们对创新的一种解释。但是这里头就用这样的一个概念去套目前常用的一些创新的词汇，这个应用比方说制度创新、体制创新、机制创新、人才理念创新、模式创新，都说得通。制度创新那就是对制度的存在的问题，利用现有的在制度应用的成果，或其他企业制度应用的成果，对我们制度应用过程中间存在的问题产生一些新的理论，并且付出行动，新的一些改变并且付出行动，那么很多。那么我认为呢，我们定义一下创新的三个要素：第一要成熟的东西，第二是有真实的需求，第三要去行动。这是我认为白话创新的三要素。

白话创新三要素有了之后，我更多的，特别是我以后的文章里头要研究的主要还是技术创新。技术创新就是说成熟技术结合什么市场需求的具体应用，这里头后面的我们所谈的技术创新、创新，都是指技术创新。我们的目的就是要解决实用主义，要让它通俗化，不要天天人们都在喊创新，那么实际上创新是个什么。我认为大家可能——当然这本来也是学术界的事情，是我们搞研究的人的事情——但是我们最后呢，人人离不开创新，每个企业离不开创新，每个人离不开创新。因此呢我们要解决实用主义，要让它通俗化，要是具体的社会需求，要和具体的社会需求和人们的生产生活需求结合起来进行创新。我们要再说一下，在我后面的文章里都讲了这个创新呢，为什么花这么大的时间想写它，我觉得写个一两万字都不成问题。就是说创新非常重要，我们现在离不开创新，但是创新的概念你都没搞清楚，那你怎么下手？你就说你自己啊，对自己嘴上天天喊的理论，如果没有准确的把握，那你的使劲的时候感觉软绵绵、心理空洞。类似的这样词汇呢，我们后面可能还会再研究其他的类似的东西。我们要做一件事，就首先要明白我们要做什么，我们做的是什么，然后才能想决心去做，哪些该做哪些不该做就更清楚。做的过程中间我们要做好这件事，我们知道了这件事之后，我们去做这件事就更有目的、更强、更不容易走偏。

在我的文章里面就好几篇文章，前面的都只要我有创新这个词，那么我一定要用对这个进行辨析，就是跟大家要进行讨论。我认为现在大家对创新的这个理念其实是含混不清，我问过很多人，他们都没有能拿出一个简单的直接的解释。那么你对创新的理解都不准确，那你这个应用怎么……所以基本上就是我认为创新，它是后面要再写的话，是创新跟创造论一论，总之后面可能我会再列出一些内容。我们先说这一段我的大概的总的思路，然后后面我们再一个一个的展开。先看看我们各个文章里面，包括收集的这些资料里面对创新的定义和技术创新的定义，和大家各方的说法，最后我们来论一个创新和技术创新。
