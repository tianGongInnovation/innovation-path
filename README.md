## 一、有什么用处

帮你看清自己到底在做什么——是创造，还是创新；该创造，还是该创新。具体能做四件事：

1. **讲清概念**：什么是创新（三要素：成熟的东西、真实的需求、具体的行动），创新和创造到底差在哪；
2. **判断方向**：拿三要素去检验你的项目、企业方向、个人打算，告诉你它算不算创新、卡在哪一要素上；
3. **给出方法**：古为今用、跨界移植、继承发扬、降本增效等七条可操作的方法，每条配真实案例；
4. **点破误区**：技术崇拜、用学历论文衡量创新、院校与企业"拉郎配"这些常见错，逐条讲清错在哪。

适合这些人用：企业经营者与管理者、一线工程技术人员、科研人员与高校教师、投资者、科技领域管理者，以及琢磨个人发展方向的普通人。

## 二、为什么要用它

"创新"这个词天天有人喊，但问一圈下来，多数人给不出一个能拿去判断的定义。市面上流传的定义往往长篇大论、术语堆砌，读完还是不知道自己该干什么。这个专家的价值在于：

- **定义可操作**：一句话、三要素，拿来就能套到自己的事情上，不是又一段听着有理的套话；
- **把创造和创新分开**：这是全篇的关键。混淆这两个词，会让企业去干它干不了的创造，让院校去干它干不好的创新，结果是干劲越大损失越大；
- **有实践底子**：理论来自几十年一线创新实践和无数次讨论打磨，不是书斋里的推演；
- **讲人话、有立场**：不给模棱两可的答案，判断就给判断，理由摆出来供你自己权衡。

## 三、怎么用

安装后，在 WorkBuddy 的「专家」里找到「创新之路」，直接问就行。三个推荐的开场问法：

- 创新到底是什么？怎么定义的？
- 创新和创造区别在哪里？我现在做的是创造还是创新？
- 企业做前沿科技对不对？院企结合、校企结合对不对？为什么？

**怎么问效果最好**：把你所在的行业、手头的条件、想解决的具体问题说清楚，越具体，判断越准。想深入可以追问"这个需求是真的吗""有没有更省力的做法""这个方向值不值得做"。

## 四、有问题怎么办

| 遇到什么情况 | 怎么处理 |
|---|---|
| 判断听上去太武断 | 要求它按三要素逐条拆解说明，看完再自己定夺 |
| 涉及具体投资决策 | 专家只做创新属性与方向分析，不代替投资决策；涉及收益与风险的判断请另行评估 |
| 你不同意它的观点 | 直接摆出你的看法，它会据理讨论。这套理论是一家之言，欢迎争论，不强行灌输 |
| 想核实某个案例或出处 | 请它说明案例来源；专家自带知识库，重要论述都能指到具体篇章 |
| 回答有误或表述不当 | 直接用自然语言纠正，它会当场修正；重要问题建议交叉核对原始资料 |
